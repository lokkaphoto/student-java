# Лабораторная работа 2. Классы и инкапсуляция

## Инварианты класса BankAccount:
- Баланс не может быть отрицательным при создании.
- Пополнение (deposit) возможно только на положительную сумму.
- Списание (withdraw) возможно только на положительную сумму, не превышающую текущий баланс.

## Инварианты класса DataSample:
- id не равен null и не является пустой строкой.
- label не равен null и не является пустой строкой.
- Массив features не равен null и не пустой.
- Внутренний массив features защищен от изменений извне (копируется в конструкторе и при возврате из getter).
- Статус меняется только через специальный метод changeStatus.
